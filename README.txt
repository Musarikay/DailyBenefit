DIVINE BENEFIT WEB VERSION

This project uses the exact divine_benefit_2026.json supplied for the app.
It contains 123 entries.

FILES:
- index.html: page structure
- style.css: responsive design
- app.js: application logic
- data/divine_benefit_2026.json: devotional data

RUN LOCALLY:
1. Open Command Prompt in this folder.
2. Run: python -m http.server 8000
3. Open: http://localhost:8000

Do not double-click index.html because browsers may block loading the JSON
with fetch() from a local file.

FEATURES:
- Date selector
- Previous/Next navigation
- Search across devotional data
- Dark mode
- Responsive layout for phones, tablets, Mac and Windows

TO PUT IT ONLINE:
Upload the entire project to a static web host while preserving the data/
folder. Then share the resulting website link with your media director.
